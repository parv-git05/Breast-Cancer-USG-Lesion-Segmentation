────────────────────────────────────────────────────────────────────────────────
1. PROBLEM STATEMENT
────────────────────────────────────────────────────────────────────────────────
Build a reproducible medical computer-vision pipeline for B-mode breast
ultrasound (BUS) lesion analysis on the BUSI dataset.

Phase 1 Goal A: Binary lesion segmentation — given a BUS image with one
ground-truth mask, predict a binary pixel mask (lesion=1, background=0).

Phase 1 Goal B: Malignancy classification — given a BUS image and a
segmentation-derived ROI, classify benign vs malignant.

The pipeline must be leakage-safe, metric-correct, config-driven, and
structured so that baseline results are trustworthy before any advanced
model is attempted.

This is a research/educational project. It is NOT a clinical diagnostic
system. Model outputs must not be used to make or infer clinical diagnoses.

6. MODULE RESPONSIBILITIES
────────────────────────────────────────────────────────────────────────────────
audit.py
  - Walk raw dataset folder; count images and masks per class.
  - Detect multi-mask cases (multiple mask files for one image).
  - Detect empty masks (zero nonzero pixels).
  - Detect dimension mismatches between image and mask.
  - Detect presence/absence of the deleted duplicate pair (log as expected
    absent; do not error).
  - Output: console report + optional JSON summary. Never writes to raw folder.

manifest.py
  - Load and validate BUSI_phase1_manifest.csv.
  - Assert: row count == 628, benign == 420, malignant == 208.
  - Assert: every referenced file exists on disk.
  - Assert: no row appears in BUSI_phase1_excluded.csv.
  - Raise clear errors on contract violations.

split.py
  - Input: BUSI_phase1_manifest.csv, seed (from config), ratios (70/15/15).
  - Stratify by class (benign/malignant) using sklearn or equivalent.
  - Write: data/splits/train.csv, val.csv, test.csv.
  - Assert splits are disjoint.
  - Assert class distribution is approximately preserved.
  - Record seed and exact counts in a split_metadata.json.
  - Expected approximate sizes: ~439 train / ~94 val / ~95 test.
    Exact counts are computed by code; do not hardcode them.
  - README must note: image-level split, not patient-wise (see §3 caveat).

dataset.py
  - PyTorch Dataset wrapping a split CSV.
  - Load image as grayscale, load mask as binary.
  - Apply transforms from transforms.py.
  - Validate: image and mask spatial dims match after loading.
  - Raise graceful errors for: missing file, corrupt file, empty mask,
    non-binary mask values after preprocessing.
  - DataLoader: configurable batch size, num_workers; deterministic for
    val/test (shuffle=False, no random augmentation).

transforms.py
  - All resize operations: image uses bilinear (or configurable); mask uses
    nearest-neighbor ONLY.
  - Target size is read from config; must not be hardcoded in callers.
  - Grayscale conversion.
  - Intensity normalization (e.g. [0,1] or z-score); method configurable.
    If statistics are fit (mean/std), fit on train set only.
  - Training augmentations: horizontal flip, vertical flip, rotation,
    brightness/contrast jitter, elastic deformation (TBD — add only if
    clinically plausible and implemented correctly for image+mask pairs).
    All augmentations applied identically to image and mask.
  - Val/test: deterministic pipeline only (resize + normalize). No random ops.
  - All augmentation parameters configurable; augmentation can be disabled.

models/unet.py
  - Plain U-Net: encoder-decoder with skip connections.
  - Configurable depth and base feature channels.
  - Input channels: 1 (grayscale). Output channels: 1 (logit for binary mask).
  - No attention gates, no transformers, no CBAM in Phase 1.
  - Architecture params stored in config and saved in checkpoint.

losses.py
  - Dice loss (operating on probabilities after sigmoid).
  - Binary cross-entropy (BCEWithLogitsLoss preferred for numerical stability).
  - Combined Dice+BCE with configurable weighting.
  - Each loss independently testable.

metrics.py  [KEEP INDEPENDENT OF TRAINING CODE]
  Segmentation:
    - Dice coefficient (DSC)         [PRIMARY]
    - IoU / Jaccard                  [PRIMARY]
    - Precision (pixel-level)
    - Recall / Sensitivity (pixel-level)
    - Specificity (pixel-level)
    - HD95 (Hausdorff 95th percentile) — implement only if reliable; TBD
    - Do NOT use pixel accuracy as a primary metric
  Classification:
    - ROC-AUC
    - PR-AUC
    - Sensitivity / Recall
    - Specificity
    - Precision
    - F1
    - Balanced accuracy
    - Confusion matrix (absolute + normalized)
    - Do NOT report accuracy alone
  Each metric function: takes numpy arrays; has a unit test.

train.py  (segmentation)
  - Config-driven: reads YAML for all hyperparameters.
  - Records: model arch, loss, optimizer, LR, batch size, image size,
    seed, augmentation flags, start time, environment.
  - Trains for configured epochs; evaluates on val set each epoch.
  - Checkpoints best model by validation Dice. Saves full config in checkpoint.
  - Logs: train loss, val loss, val Dice, val IoU per epoch (CSV + console).
  - Deterministic mode: set seed for Python, NumPy, PyTorch, CUDA.
  - GPU when available; CPU fallback; device read from config or auto-detected.
  - Never reads from or evaluates on test set during training.

evaluate.py
  - Loads a checkpoint; runs inference on a specified split (train/val/test).
  - Computes all segmentation metrics (per-image and aggregate).
  - Saves: metric CSV, qualitative overlays (image / GT mask / predicted mask).
  - Test set must be evaluated ONCE, only after final model selection from val.
  - Evaluation code must not import or call any training-loop code.

classify.py
  - Derive lesion ROI from a mask (GT or predicted): bounding box crop with
    configurable padding; or full-image path.
  - Two strictly separate experiment modes:
      ORACLE:    ROI derived from ground-truth mask.
      PREDICTED: ROI derived from U-Net predicted mask.
    These two modes must not mix crops or share evaluation records.
  - Baseline model: ResNet18 or EfficientNet-B0; configurable; pretrained
    weights optional (configurable). No complex architecture in Phase 1.
  - Binary label: benign=0, malignant=1.
  - Address class imbalance with weighted loss or weighted sampler using
    training set only.
  - Save: checkpoint, metric CSV, ROC curve, PR curve, confusion matrix.

visualize.py
  - Overlay: original image + GT mask + predicted mask (colour-coded).
  - Grid of N random train/val/test samples for sanity checking.
  - Failure-case visualization: worst Dice predictions on val/test.
  - Save as PNG to outputs/reports/; do not display interactively in
    non-interactive environments.

utils.py
  - set_seed(seed): sets Python random, NumPy, torch, torch.cuda seeds.
  - get_device(): returns CUDA if available, else CPU.
  - load_config(path): loads YAML; validates required keys.
  - save_checkpoint / load_checkpoint: includes full config dict in payload.
  - Timer / epoch-time logging helper.

  {0, 1} integer or {0.0, 1.0} float. Empty masks (all zero) raise a
  warning and are flagged; not silently accepted.

  Config:      configs/exp_seg_01.yaml
  Split:       train.csv / val.csv

  Selection:   best checkpoint = highest val ROC-AUC

EXP-CLS-02   Malignancy classification — predicted ROI
  Input:       EXP-SEG-01 predicted masks → cropped ROI
  Config:      configs/exp_cls_predicted.yaml  (roi_mode: predicted)
  Note:        use EXP-SEG-01 test-set predictions; do not re-run training
               with test-derived knowledge
  Selection:   checkpoint from EXP-CLS-01 (same architecture) OR retrained
               on train-set predicted masks from EXP-SEG-01's train inference;
               document clearly which was done.
  Evaluation:  ONCE on test.csv after selection

COMPARE-01   Segmentation quality vs classification gap analysis
  Compare EXP-CLS-01 vs EXP-CLS-02 metrics on the same test set.
  Identify whether predicted-ROI degrades classification and by how much.

Rule: no advanced models (attention, transformers, etc.) are started until
EXP-SEG-01 and EXP-CLS-01 are completed and results are inspected.

10. LEAKAGE CONTROL RULES
────────────────────────────────────────────────────────────────────────────────
L1  Image and its mask are always kept in the same split.
L2  No image appears in more than one split. Assert this programmatically.
L3  Val and test sets receive NO random augmentation; preprocessing only.
L4  Test set is evaluated ONCE per experiment, after all model selection is
    done using validation metrics. Never tune on test results.
L5  Normalization statistics (if learned) are computed on train set only
    and applied to val/test without refitting.
L6  Model predictions are never used to generate or alter ground-truth labels.
L7  Ground-truth masks are never manually altered by code; if a future manual
    correction is made, it must be documented with reason and date.
L8  Classification ROI in EXP-CLS-02 must come from predictions produced
    without test-set leakage (model not trained/selected using test labels).
L9  Audit trail: BUSI_phase1_excluded.csv documents all excluded cases.
    No excluded multi-mask case enters any split.
